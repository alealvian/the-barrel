The Barrel — a colossal curling wave swallowing the sun, with a tiny surfer silhouetted inside the tube. A Python program that draws it, pixel by pixel, in pure stdlib — no image files, no network, fully deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
